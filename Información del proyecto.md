# Proyecto-TSDS
Aquí estará todo el código fuente y la documentación del proyecto de restobares, parte de la asignatura de Talleres de Sistemas de Software.

Inicialmente se debe documentar cada cambio dentro del proyecto para que así quienes revisen las cápsulas en cada sprint sepa que se hizo, cuando se hizo y por que se hizo. Tampoco es necesesario documentar cada paso de un código, use su criterio para comentar cambios, así el código será más legible y fácil de seguir.

*Por favor, use IA si estima conveniente, pero no deje que la IA lo use a usted.*
